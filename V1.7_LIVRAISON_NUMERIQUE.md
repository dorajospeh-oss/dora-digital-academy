# DORA DIGITAL ACADEMY — V1.7

## Livraison numérique sécurisée
- Bibliothèque client basée sur `get_my_library()`.
- Téléchargement via l’Edge Function `secure-download`.
- URL de fichier signée temporaire, jamais exposée directement dans le catalogue.
- Contrôle serveur de l’accès, de l’expiration et de la limite de téléchargements.
- Enregistrement du téléchargement dans `downloads`.
- Après paiement confirmé par le webhook, `product_access` est créé automatiquement côté Supabase.

## Pré-requis production
Le fichier numérique doit être présent dans le bucket privé `digital-files` et `products.file_path` doit pointer vers son chemin.
Le PDF pilote `1 300+ Prompts IA pour le Business` doit encore être envoyé via le workflow d’administration sécurisé.

## Flux
Paiement confirmé → `apply_payment_webhook()` → `product_access` → notification → bibliothèque → `secure-download` → URL signée temporaire.
