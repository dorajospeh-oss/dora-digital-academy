# V1.15 — Déploiement production

## Vercel

1. Importer le dépôt Git dans Vercel.
2. Framework : Next.js.
3. Build : `npm run build`.
4. Installer : `npm install`.
5. Ajouter les variables :
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
   - `NEXT_PUBLIC_SITE_URL`
6. Ne jamais ajouter `SUPABASE_SERVICE_ROLE_KEY` dans les variables exposées au navigateur.

## Supabase Auth

Configurer le Site URL et les Redirect URLs avec le domaine de production, notamment `/auth/callback`.

## Domaine

Connecter le domaine définitif dans Vercel puis remplacer `NEXT_PUBLIC_SITE_URL` par ce domaine.
