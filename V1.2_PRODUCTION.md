# DORA DIGITAL ACADEMY — V1.2

## Objectif
Préparation de la vitrine publique pour Vercel : identité, métadonnées SEO, Open Graph, favicon, robots.txt et sitemap.

## Variables Vercel
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

Ne jamais ajouter SUPABASE_SERVICE_ROLE_KEY au frontend.

## Domaine
Le placeholder Vercel est `dora-digital-academy.vercel.app`. Après attribution du domaine final, remplacer `metadataBase` et les URLs robots/sitemap par le domaine officiel.

## Vérification
Lancer `npm install` puis `npm run build` dans l'environnement de déploiement. Le build n'est pas déclaré validé dans cet environnement tant qu'il n'a pas été exécuté avec succès.
