# V1.16 — Lancement final

## Go / No-Go

Le projet est prêt au lancement technique lorsque tous les points suivants sont verts :

- [ ] Domaine de production connecté.
- [ ] Variables Vercel renseignées.
- [ ] Auth Supabase configurée avec le domaine final.
- [ ] Build Vercel réussi.
- [ ] Paiement marchand réellement configuré.
- [ ] Secret webhook configuré.
- [ ] Produit numérique réellement présent dans `digital-files` avec `file_path` correct.
- [ ] Test d'achat réel réussi.
- [ ] Test de téléchargement réussi.
- [ ] Test formation/quiz/certificat réussi.
- [ ] Test mobile réussi.
- [ ] Mentions légales et politique de confidentialité adaptées aux informations juridiques réelles de l'exploitant.

## Statut

La base logicielle DORA DIGITAL ACADEMY est consolidée jusqu'à V1.16. Les éléments cochés ci-dessus dépendent de comptes et identifiants externes qui ne peuvent pas être inventés ou activés automatiquement.
