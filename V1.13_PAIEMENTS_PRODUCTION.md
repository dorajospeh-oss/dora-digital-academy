# V1.13 — Paiements production

## Architecture

1. Le client crée une commande via une fonction Supabase sécurisée.
2. Le frontend appelle `start_payment`.
3. Le prestataire externe traite le paiement.
4. Le webhook signé appelle `payment-webhook`.
5. `apply_payment_webhook` confirme la transaction côté serveur.
6. Les accès produits sont créés après confirmation.

## Configuration encore externe

Les identifiants marchands/API des prestataires Orange Money, Airtel Money, Moov Money, Visa/Mastercard ne sont pas fournis dans le projet. Ils doivent être ajoutés uniquement dans l’environnement serveur/Edge Function du prestataire concerné.

Ne jamais mettre une clé secrète de paiement ou `service_role` dans Next.js/Vercel côté navigateur.
