# DORA DIGITAL ACADEMY — V1.5

## Authentification professionnelle
- Inscription email + mot de passe
- Confirmation email via `/auth/callback`
- Connexion avec redirection vers la destination demandée
- Mot de passe oublié
- Réinitialisation du mot de passe
- Déconnexion
- Sessions SSR via cookies avec `@supabase/ssr`
- Protection serveur des espaces `/compte`, `/apprentissage`, `/paiement` et `/admin`
- Vérification serveur avec `auth.getClaims()`
- Aucun `service_role` dans le frontend

## Configuration Supabase Auth
Dans Supabase > Authentication > URL Configuration :
- Site URL : domaine Vercel final
- Redirect URLs : `https://VOTRE-DOMAINE/auth/callback`
- Pour le développement : `http://localhost:3000/auth/callback`

Les URLs de récupération utilisent automatiquement `/auth/reset-password` sur le domaine courant.
